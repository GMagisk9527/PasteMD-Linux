# Third-Party Notices

PasteMD Linux calls or packages the following third-party components. They are not committed as source or binaries in this repository; release builds download pinned versions and include their license files. Each component remains under its own license and copyright.

- [Pandoc 3.7.0.2](https://github.com/jgm/pandoc/tree/3.7.0.2) — document conversion; packaged builds include its license and copyright files
- [Qt for Python / PySide6](https://doc.qt.io/qtforpython-6/) — graphical interface, tray, clipboard ownership and local IPC
- [dbus-python 1.4.0](https://dbus.freedesktop.org/releases/dbus-python/) — KDE session D-Bus access; packaged in Flatpak
- [PyGObject 3.56.3 / GLib](https://download.gnome.org/sources/pygobject/3.56/) — D-Bus event dispatch; packaged in Flatpak
- [wl-clipboard 2.2.1](https://github.com/bugaevc/wl-clipboard/tree/v2.2.1) — Wayland clipboard input; packaged builds include its license file
- [Xlib](https://gitlab.freedesktop.org/xorg/lib/libx11) — XWayland focus and window inspection
- [XTest](https://gitlab.freedesktop.org/xorg/lib/libxtst) — focus-checked Ctrl+V delivery

Qt for Python Community Edition is offered under LGPLv3/GPLv3; see the [official Qt for Python licensing page](https://doc.qt.io/qtforpython-6/licenses.html). Consult each linked project for its complete and current license terms.
