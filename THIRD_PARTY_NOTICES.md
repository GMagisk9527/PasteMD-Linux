# Third-Party Notices

PasteMD Linux calls or loads the following system-provided components. They are not vendored in this repository and remain under their respective licenses and copyrights.

- [Pandoc](https://github.com/jgm/pandoc) — document conversion
- [Qt for Python / PySide6](https://doc.qt.io/qtforpython-6/) — graphical interface, tray, clipboard ownership and local IPC
- [dbus-python](https://gitlab.freedesktop.org/dbus/dbus-python) — KDE session D-Bus access
- [PyGObject / GLib](https://pygobject.gnome.org/) — D-Bus event dispatch
- [wl-clipboard](https://github.com/bugaevc/wl-clipboard) — Wayland clipboard input
- [Xlib](https://gitlab.freedesktop.org/xorg/lib/libx11) — XWayland focus and window inspection
- [XTest](https://gitlab.freedesktop.org/xorg/lib/libxtst) — focus-checked Ctrl+V delivery

Qt for Python Community Edition is offered under LGPLv3/GPLv3; see the [official Qt for Python licensing page](https://doc.qt.io/qtforpython-6/licenses.html). Consult each linked project for its complete and current license terms.
